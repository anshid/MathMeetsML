# Data

No files are downloaded at runtime. All datasets ship inside the pinned `scikit-learn` package:

- `sklearn.datasets.load_digits`: 8x8 handwritten digits, a copy of the UCI "Optical Recognition of Handwritten Digits" test set (E. Alpaydin, C. Kaynak, Bogazici University). Free for use with citation.
- `sklearn.datasets.load_sample_images`: two sample photos (china.jpg, flower.jpg) released under CC-BY 2.0 (china.jpg by danielbuechele, flower.jpg by vultilion on Flickr; retrieved 2011 by Robert Layton for scikit-learn). Credit the photographers if you reuse them.
