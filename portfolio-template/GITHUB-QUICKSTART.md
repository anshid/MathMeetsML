# GitHub in 10 minutes (no command line needed)

## 1. Make an account
Go to github.com, sign up, pick a simple username (you will put it on your CV).

## 2. Create a repository for your project
1. Click **+** (top right) -> **New repository**.
2. Name it, for example `gradient-descent-golf`. Tick **Add a README**. Keep it **Public**. Click **Create**.

## 3. Upload your notebook
1. In Colab: **File -> Download -> Download .ipynb**.
2. In your new repo: **Add file -> Upload files**, drop the `.ipynb` (and a picture of your result), then **Commit changes**.

## 4. Fill in the README
Open `portfolio-template/README-template.md` from the workshop repo, copy its text into your repo's `README.md` (pencil icon to edit) and fill the blanks.

## 5. No GitHub today? Export a PDF
In Colab or Jupyter: **File -> Print -> Save as PDF**. Attach the PDF to your CV or email.

## 6. Share
Post your repo link in the group chat.
