# Quests (take-home)

Quests are optional challenges after the session. Finish one, put it in your own GitHub repo (see `../portfolio-template/`) and share the link in the group chat. The best ones go in the Hall of Fame.

| Mission | Quest | Done when |
|---|---|---|
| 1 Gradient Descent Golf | Fit a line $y\approx 2x+1$ by gradient descent and compare with the normal equation $(X^\top X)^{-1}X^\top y$ | Your $w,b$ match the closed form to 3 decimals, plus a plot of the loss falling |
| 2 Digit Reader | Confusion matrix and the 12 most confidently wrong digits | You can name the two most confused digits and explain it using the weight images |
| 3 Selfie Compressor | Compress your own photo | You report the smallest rank $k$ with relative error under 5% and the storage fraction |
| 4 Mini-Google & Names | Name generator on 50 names of your choice | 20 invented names and the three most common letters of the stationary distribution |
| 5 Inside a Tiny AI | Add a second hidden layer, or train the net on digits | Gradient check passes and you report test accuracy vs Mission 2 |

## Optional add-ons (try after the quests)
- **Bayesian coin toss** (Applied Probability, Unit I): start with a Beta(1,1) prior, update after each toss, plot the posterior.
- **Optimizer race**: gradient descent vs momentum on the same valley from Mission 1, plotted together.

Stuck? Ask in the group chat. Explaining your approach to someone else counts as progress.
